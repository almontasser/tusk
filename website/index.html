Laravel fluently

An editor for Laravel
and Filament developers

Tusk understands the strings Laravel and Filament resolve at runtime, like routes, views, config keys, and model columns, so completion and ⌘-click work where other editors see plain text.

  • Filament completion from your Eloquent models
  • Routes, views, and config through Laravel LSP
  • Blade and Tailwind CSS, highlighted and completed
  • Pest and PHPUnit with one-click Run, Debug, and Profile
Explore Laravel features ↗

An HTTP client that reads your routes

Requests live in .http files your team commits with the code. Tusk writes them from route:list, with JSON bodies built from each FormRequest's rules.

  • Environments, secrets, scripts, and tests
  • Import from curl, Postman, Insomnia, and OpenAPI
  • GraphQL, WebSockets, stress tests, and JUnit reports
Explore the HTTP client ↗

Your database, straight from .env

The Database tool window connects the way Laravel does. SQLite, MySQL, MariaDB, and PostgreSQL drivers are built in, so there's no client to install.

  • Run SQL with ⌘⏎ and edit rows in the grid
  • Connect over SSH to a server's database
  • TLS settings from the same keys Laravel reads
Explore the database tools ↗

AI completion that never leaves your Mac

Qwen2.5-Coder runs locally on your Mac's GPU. It reads the classes your file uses, so its suggestions call methods that exist. Press Tab to accept, or ⌘→ to take one word.

  • No account, no subscription, no code sent anywhere
  • Choose a 1.5B, 3B, or 7B model

Git and pull requests, built in

Stage single lines, commit, and push. Review GitHub pull requests with their checks, diffs, and threads, and comment right on the lines.

  • Blame, log, stash, worktrees, and interactive rebase
  • Resolve merge conflicts side by side
  • Local history that keeps every save, even without git

Batteries included.

[ Beta ]

Tusk is in beta.

Tusk is ready for daily work, and it's still young. Expect rough edges, and expect them to get fixed quickly. The code is open on GitHub, where you can report what you find.

  • PlatformmacOS only, on Apple silicon and Intel Macs.
  • SigningThe app isn't signed yet. The first time you open it, allow it in System Settings > Privacy & Security.
  • UpdatesThere's no auto-update. Each version is a new download.
  • GapsSome PhpStorm features are missing. The known gaps list them.
