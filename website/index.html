The PHP editor that speaks Laravel.

Tusk is a fast macOS editor for PHP, Laravel, and Filament. You get PhpStorm-class navigation and refactoring, an HTTP client, a database console, a debugger, and local AI completion, all in one native window.

Laravel and Filament

It knows your models, routes, and resources.

Tusk understands the strings Laravel and Filament resolve at runtime, so completion and ⌘-click work where other editors see plain text.

Filament, understood

A Filament language server reads your Eloquent models. In ::make('…') it suggests columns and relationships, follows 'author.' into the related model, and flags a relationship your model doesn't define.

  • Enum options and defaults from your casts
  • ⌘B from 'author' to the model's author() method
  • Links between resources, pages, and relation managers

Blade and Tailwind, highlighted properly

Blade files highlight their HTML, the PHP inside {{ }}, directives, and component tags. Tailwind classes complete with their CSS, and colors show a swatch you can click to change.

  • ⌘-click view('welcome'), routes, config keys, and translations
  • ⌘B on <x-card> opens the component
  • Blade formatting with your project's own settings

Pest and PHPUnit, one click away

Every test gets Run, Debug, and Profile links. Results land in a tree with timings, failures jump to the line, and coverage shows in the gutter. Run Anything (⌃⌃) starts Artisan commands, npm run dev, or Tinker, in Sail when it's running.

  • ⌃⇧R runs the test at the cursor, ⌃R reruns the last one
  • Line coverage, and which tests ran each line
  • Servers you started come back when the project reopens
Built-in tools

Stop switching apps.

The HTTP client, database console, and git tools you reach for every hour live in the same window as your code.

An HTTP client for your API

Requests live in .http files that PhpStorm and VS Code also read, so your team commits them with the code. Tusk can write them for you from route:list, with a JSON body built from each FormRequest's rules.

  • Environments, secrets, scripts, and tests
  • Import from curl, Postman, Insomnia, and OpenAPI
  • GraphQL, WebSockets, stress tests, and JUnit reports for CI

Your database, from .env

The Database tool window connects the way Laravel does. SQLite, MySQL, MariaDB, and PostgreSQL drivers are built in, so there's no client to install. Browse tables, edit rows, and run SQL with ⌘⏎.

  • Edit rows in the grid and submit them together
  • Connect over SSH to a server's database
  • TLS settings read from the same .env keys as Laravel

Git and pull requests

Stage lines, commit, and push without leaving the editor. Review GitHub pull requests with their checks, diffs, and threads, and comment right on the lines.

  • Blame, log, stash, worktrees, and interactive rebase
  • Resolve merge conflicts side by side
  • Local history that keeps every save, even without git
And much more

Everything a PHP developer needs.

Tusk bundles its tools and compiles in its database drivers. PHP on your PATH is the only thing you bring.

AI completion that stays on your Mac

Qwen2.5-Coder runs locally on Apple silicon's GPU. It reads the classes your file uses, so suggestions call real methods. Press Tab to accept, or ⌘→ to take one word.

public function publish(Post $post): RedirectResponse { $post->update(['status' => PostStatus::Published]); return redirect()->route('posts.show', $post); }

Xdebug debugger

Breakpoints with conditions and log messages, watches, and exception filters. Debug a test, a page, or a request from the HTTP client, in Docker and Sail too.

Profiler

Profile a test or a URL with one command and find the slow function in a sortable call table, with callers and callees.

Refactoring

Rename, extract method, change signature, inline variable, and safe delete. Moving a file moves its class and fixes every reference.

Search everywhere

Press ⇧⇧ to find classes, files, symbols, actions, and HTTP requests. Find in files handles regex and replaces across the project.

Static analysis

Mago and your project's Larastan check as you type. Problems show inline, and ⌥⏎ fixes what it can.

Composer

Search Packagist, require and update packages, and see outdated ones, with a bundled Composer.

JavaScript, TypeScript, and Vue

Full language servers for TypeScript, Vue, Svelte, and Astro start the first time you open one of their files.

110 themes

PhpStorm-like Dark and Light, plus One Dark Pro, Dracula, Catppuccin, Tokyo Night, and more. Import any VS Code theme.

Beta

Tusk is in beta.

Tusk is usable every day, and it's still young. Expect rough edges, and expect them to get fixed quickly. The code is open on GitHub, where you can report what you find.

During the beta:

  • Tusk runs on macOS only, on Apple silicon and Intel Macs.
  • The app isn't signed yet, so the first time you open it, allow it in System Settings > Privacy & Security.
  • There's no auto-update. Each version is a new download.
  • Some PhpStorm features are missing. The known gaps list them.
